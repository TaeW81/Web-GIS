# 토지보상비 자동 산정 — 데이터 출처 및 적용 방법

## 1. 산정 공식

```
보상배율 = (용도지역 배율 + 이용상황 배율) / 2
토지보상비(원) = 개별공시지가(원/㎡) × 면적(㎡) × 보상배율
```

→ **이 공식은 임의가 아니라 국가 예비타당성조사의 공식 방법론**입니다. (기획재정부 「예비타당성조사 수행 총괄지침」 2018.4)

## 4. 산정 절차 (지침 p.82, 3단계)

```
1단계: 필지의 [용도지역 + 이용상황 + 공시지가] 확인 가능 여부 판단
       └─ 부동산공시가격알리미 / 지자체 개별공시지가 DB

2단계: 감정평가 / 보상사례 / 실거래가 확인
       └─ 있으면 그 값 사용

3단계: 표 Ⅳ-28의 시도별 보상배율 적용
       └─ 보상배율 = (용도지역 배율 + 이용상황 배율) / 2
       └─ 둘 중 하나만 알면 그 배율만 적용
       └─ 둘 다 모르면 시도 전체 배율 적용
```

## 6. 국공유지 처리 (사용자 요청 반영)

소유자가 **국유지/공유지/군유지/도유지/시유지**인 경우:
- 용도지역(보상) S열 → **빈칸**
- 보상배율(용도) T열 → **빈칸**
- 이용상황(보상) U열 → **"국ㆍ공유지"** 고정
- 보상배율(이용) V열 → **빈칸**

근거: 예타지침 「용지보상비 관련 보상배율 및 예비비 포함 여부」 (표 Ⅳ-29)에 따라 국공유지는 별도 산정.

## 7. 데이터 갱신 가이드

### 7.1 회사 사내 표준 배율표가 정해질 때
`data/compensation_ratio.json` 파일의 `ratios_by_sido` 부분만 교체. 코드 수정 불필요.

### 7.2 시기 보정이 필요할 때
한국부동산원 지가변동률(R-ONE)을 활용해 연도별 보정 가능. `_meta.notes` 참고.

### 7.3 KDI 개정판이 나왔을 때
`_meta.documents` 마지막 항목(KDI 17226)에서 최신 데이터 입수 후 `ratios_by_sido` 부분 갱신.

## 8. 주의사항

이 자동 산정은 **예비 사업비 추정용**입니다 — **법적 보상가가 아닙니다**.

| 단계 | 산정 방법 |
|---|---|
| 타당성 검토 (현재 자동조서 단계) | 표 Ⅳ-28 보상배율 적용 |
| 기본설계 | 약식 감정평가 의뢰 |
| 실시설계·보상 | 정식 감정평가 (법적 효력) |
