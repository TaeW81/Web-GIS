# 현황분석 보고서 확장 로드맵

> 목표: `report/status_report_generator.py`가 채우는 현황분석 보고서(HWPX)에
> **「강원특별자치도 태백시 통동 일원_편집중2.pdf」(1~27p)** 의 모든 분석 섹션을
> 자동 생성하도록 확장한다. (PDF 28~29p = 데이터 출처표 → 자동작성 대상 아님)

확정 사항
- **구간(bin) 산정 = 등간격 자동 (min~max 5구간)**
- 양식 없는 섹션은 **지목별 섹션 블록을 복제**해 자동 생성 (`제2장_개발여건분석.hwp`는 시각 참고만)
- **API 신규 연결이 필요한 섹션은 맨 마지막(Phase 5)에 구현**
- 보고서 섹션 번호는 기존 소유자별·지목별을 **연번에 포함**해 장(章)별로 연속 정리

## 2. 구현 빌딩블록

이미 구현(재사용):
- `_make_cell`·`_bf_def`·`_ensure_table_borderfills` — HWPX 표 셀/테두리
- `_build_jimok_table_xml` 패턴 — 5열 세로형 표(구역계/면적오차/계 + 항목)
- `_make_category_map_image` — V-World 배경 + 범주 색칠 + 범례 + 방위/축척
- `_replace_*_section`·`_replace_*_image`·`_prune_unused_bindata`·`_delete_unwritten_sections`

신규 공통(Phase 1에서 선반영):
1. `_equal_interval_bins(values, n=5)` — min~max 등간격 구간 + 면적/필지수 집계(희소 시 구간 축소)
2. `_build_status_table_xml(orig, stats, schema)` — 지목별 빌더 일반화
   (옵션: 필지수 컬럼 유무 / 면적오차·계 행 유무 / 추가컬럼 최고·최저·평균)
3. `_make_regulation_section(...)` — `fetch_wfs_data`로 받은 WFS 폴리곤을 구역계와 교차·범주 집계 후 표+현황도
4. `_clone_section(...)` — 지목별 블록 복제 → 제목·캡션·표·이미지 치환 후 삽입
5. 카테고리 색상 팔레트 확장(`_JIMOK_COLOR` 패턴)

## 3. 단계별 실행 계획 (API 신규는 최후)

### Phase 1 — 토지대장 확장  ★ 즉시
- **2-3 면적별 · 2-4 공시지가별** (기존 land_data: 편입면적·공시지가)
- 등간격 binning + 범용 표 빌더 + 범주 현황도. 양식: 면적별=복제 / 공시지가별=샘플 보유.

### Phase 2 — V-World 규제 범주형 일괄 (데이터 연결됨)
- **4-1~4-3 용도지역/지구/구역, 4-7 지구단위, 5-1 농업진흥, 5-2 산지, 5-3 하천,
  5-4 문화재, 5-5 상수원, 5-6 도로구역, 3-3 생태자연도, 3-4 국토환경성평가**
- 공통 `_make_regulation_section` 엔진 1개 + 섹션별 설정(레이어코드·카테고리필드·색·캡션).

### Phase 3 — 자연환경 래스터
- **3-1 표고**(elevation_analyzer 재사용, C형 표) · **3-2 경사**(DEM 경사 산출 신규)

### Phase 4 — 복합/맞춤 표
- **3-5 임상도×4, 3-6 수리·수문(8열), 4-4 도시계획시설(교통, 도로총괄 16열),
  4-5 공간시설, 4-6 기타시설, 5-10 기타 공적규제**
- 비표준 표는 섹션별 맞춤 빌더. 데이터 세부 구조 확인 후 진행.

### Phase 5 — API 신규 연결 (제일 마지막)
- **2-5 토지피복**(환경부 토지피복지도) · **5-7 초지** · **5-8 교육환경보호구역** · **5-9 접도구역**
- 각 공공 API/소스 확보 → 연결 → 동일 범주형 패턴으로 생성.

### Phase 6 — 통합/조립
- 섹션 삽입 순서·페이지 구분·장별 번호 정리, `include_*` 플래그 + app.py 섹션 선택 UI, 실데이터 통합 테스트 + 렌더 QA.

## 4. 리스크 / 미해결
1. **API 신규 4종**(토지피복·초지·교육환경·접도) — 소스 확보 필요 → Phase 5로 후순위.
2. **래스터 정확도**(경사·토지피복·임상도) — 소스·해상도 확인 필요.
3. **복합표**(도로총괄 16열·하천통계 8열) — 단순 면적집계가 아닌 속성 상세 → 원천 구조 확인.
4. **구간 숫자 차이** — 등간격 자동이라 PDF 특정 경계값과 숫자는 다를 수 있음(방식만 동일).
5. **양식 복제 한계** — .hwp 원본 미사용 → 복제 섹션 세부 서식이 PDF와 미세하게 다를 수 있음.
